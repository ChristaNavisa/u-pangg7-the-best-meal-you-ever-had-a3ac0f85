# Peanut Sauce on My Wrist

One sentence about the best meal I ever had: a satay skewer from a street vendor in Jakarta, still hissing from the charcoal, peanut sauce dripping down my wrist before I even tasted it.

The program writes that one sentence to `/output/entry.txt` — 164 characters, no title, no explanation.
